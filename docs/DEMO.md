# Career Quest: запуск и сценарий защиты

## Запуск

Нужен работающий Docker Desktop с Docker Compose. Локальные Node.js, Python и SQLite для Docker-запуска не требуются.

```bash
git clone https://github.com/BAITC-Hacks/hack-29a4db0a-radiants.git
cd hack-29a4db0a-radiants
docker compose up --build
```

Открыть http://localhost:3000. Один контейнер содержит Next.js, frontend, backend и SQLite. При первом старте автоматически загружаются 200 сотрудников, 40 мероприятий, 60 навыков, 32 ролевых профиля и 2743 записи истории. `/api/health` показывает готовность и количества.

Для AI-объяснений перед запуском сохранить серверный `OPENAI_API_KEY` в `.env` рядом с `compose.yaml`. Без ключа всё приложение работает с объяснениями, сформированными кодом. `.env` исключён из Git и Docker image. При изменении ключа выполнить `docker compose up -d --force-recreate`, чтобы обновить окружение контейнера.

Остановка: `docker compose down`. Повторный запуск сохраняет данные в named volume. Явный сброс демо: `docker compose down -v` — удаляет данные этого compose-проекта. Если порт занят, задать `APP_PORT=3001` в `.env` и открыть http://localhost:3001.

## Сценарий на 3–5 минут

1. Открыть сотрудника E0178. На чистой базе readiness 71.3%. Показать карьерную цель, критические gaps и ожидаемые изменения навыков.
2. Показать обычные объяснения сразу после открытия. Дождаться AI-assisted explanation; если провайдер недоступен или медленный, приложение сохраняет объяснения по правилам. Числа, eligibility и порядок рекомендаций рассчитывает код.
3. Завершить System Design Fundamentals (EV_005). Readiness становится 74.1%, прирост +2.8 п.п.; API Design остаётся 4. История и рекомендации обновляются без ожидания AI.
4. Перезагрузить страницу: прогресс сохранён. Показать завершённые активности и отдельный блок обязательных мероприятий.
5. Импортировать `docs/fixtures/jury-employee.json`, затем `docs/fixtures/jury-history.csv` через Import. Это дополнительный синтетический профиль, а не замена каталога. Его readiness меняется с 71.3% до 74.1% после CSV; появляется завершённый EV_005 и отдельное обязательство EV_001 overdue. Затем можно завершить следующую рекомендованную активность.
6. Открыть HR dashboard: показать частые gaps, сотрудников без следующего шага и статусы участия. Перейти из HR к выбранному сотруднику.

## Что сказать об архитектуре

- Детерминированный движок восстанавливает навыки по истории после последнего review, определяет цель и допустимые активности, ранжирует по gaps и истории участия.
- ИИ получает только уже выбранные мероприятия и evidence; сервер проверяет структуру, event IDs и ссылки на факты. ИИ дополняет объяснения, не изменяя навыки или readiness.
- Профиль и completion отвечают независимо от LLM. Провайдер ограничен 8 секундами, общий AI-бюджет — 9.5 секунды с резервом на отправку ответа.
- SQLite сохраняет completion и import транзакциями. Обновление исходной оценки навыков при completion не выполняется, поэтому прирост не учитывается дважды.

## Fallback для защиты

При проблемах сети или ключа показать работающие объяснения по правилам и явно сказать, что AI сейчас недоступен. Не называть fallback ответом модели. При повторном показе на использованной базе выбрать другой профиль или явно сбросить демо-данные заранее.

Реальная авторизация и разграничение доступа между сотрудниками не входят в MVP; employee и HR разделены на уровне интерфейса. Проверки естественного языка валидируют структуру и ссылки на evidence, но не являются доказательством каждого утверждения модели.
